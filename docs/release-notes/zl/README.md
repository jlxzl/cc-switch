# ZL 发布说明

文件名与发布标签一致：标签 `v4.0.23.1` 对应 `v4.0.23.1.md`。对外版本用主版本加序号（如 `4.0.23.1`）；内部 semver 仍保留 `-z` 后缀（如 `4.0.23-z.1`），用于自动更新的版本比较。发布工作流会把文件内容作为 GitHub Release 正文，并读取文件里的 `<!-- summary: ... -->` 作为 `latest.json` 的 `notes`（应用内更新提示）。文件缺失时回退到通用模板。

取材规则：

- 与上一版相比有上游变更：采用官方对应版本的更新说明，删掉「致谢」段落。
- 只有 ZL 自己的更新：只列自己的更新内容。
- 两者都有：官方说明（去致谢）与 ZL 更新一起列出。

官方各版本的说明在 `docs/release-notes/v<版本>-zh.md`，ZL 自己的说明放在本目录。
