# ZL 发布说明

文件名与发布标签一致：标签 `v4.0.25` 对应 `v4.0.25.md`。版本统一用三位 semver（如 `4.0.25`），内部与对外一致，不再使用 `-z` 或四段版本号。发布工作流会把文件内容作为 GitHub Release 正文，并读取文件里的 `<!-- summary: ... -->` 作为 `latest.json` 的 `notes`（应用内更新提示）。文件缺失时回退到通用模板。

取材规则：

- 与上一版相比有上游变更：采用官方对应版本的更新说明，删掉「致谢」段落。
- 只有 ZL 自己的更新：只列自己的更新内容。
- 两者都有：官方说明（去致谢）与 ZL 更新一起列出。

官方各版本的说明在 `docs/release-notes/v<版本>-zh.md`，ZL 自己的说明放在本目录。
