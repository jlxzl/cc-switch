本版本只有 ZL 自己的修正，上游内容与 4.0.23 相同。

## ZL 更新

- 关于页的官方版本状态和同步提醒默认隐藏，普通安装不再显示；需要时在关于页连点版本号 7 次，从维护开关里开启。
- 修复 4.0.23.x 子版本比较时第四段不参与排序的问题，「近期更新」不再漏掉新的子版本。
- 修复「查看完整更新内容」跳到不存在的标签导致的 404，现在打开对应版本的发布页。
- 「近期更新」只列本项目自己的发布内容，不再混入上游版本的摘要。
- 每次发布都必须提供应用内更新摘要，缺少时发布流程会直接失败。
