# CC Switch ZL 4.0.25

<!-- summary: 同步上游 v4.0.24；用量显示支持自动获取汇率（默认手动）。 -->

本版本同步上游 v4.0.24，并加入用量页自动汇率。本构建不包含 Devin 供应商。

## ZL 更新

- 用量页「设置 → 显示」新增「汇率来源」：默认手动，主动选「自动获取」后才每天联网更新一次；自动汇率与手填值分开存放，切回手动不丢原值。
- 自动取不到汇率时沿用上次缓存或手填值；按美元显示时不发请求。
- 自动模式提示后附数据来源署名，按实际数据源链到 ExchangeRate-API 或 FloatRates。

## 上游更新（v4.0.24）

授权中心加了「登录时自动打开浏览器」开关，关掉后登录只把链接复制到剪贴板，适合每个账号用独立浏览器环境的用户。同时修复了 Claude Code、Claude Desktop 经路由用 GPT 6.1 Sol / Terra 时 max 思考档位被降成 xhigh、DeepSeek Harness 选到支持 PDF 输入的模型后第三方供应商全部不显示、WSL 上启动后直接退出、Codex 的 Chat 供应商重开「支持思考等级」后档位发不出去等问题。预设方面 A6API 改用新域名 a6api.vip。

上游后续修复：路由模式的占位符不再写入 `ANTHROPIC_API_KEY`。
