# CC Switch ZL 4.0.2501

<!-- summary: 同步官方 4.0.25：MCP 连通性检查、Codex 官方额度保护、模型菜单写明供应商与实际模型等。 -->

本版本基于官方 v4.0.25（第 1 次 ZL 构建），同步官方 4.0.25 的全部更新。

## ZL 更新

- 版本号改为 `4.0.2501`：patch 按「官方 patch × 100 + ZL 序号」编码，界面、标签和安装包名保持一致。

## 上游更新

- MCP 页面新增「检查连通性」，可以一键检查所有已启用的服务器能否连上。
- Codex 用官方账号经本地路由时，可以在额度快用完前自动暂停官方请求，第三方模型照常可用。
- Claude Code 与 Claude Desktop 在路由、聚合模式下，模型菜单写明每个模型来自哪家供应商、实际是哪个模型。
- Codex 供应商表单可以设置子代理并发上限；会话管理可以删除 Kimi Code 会话。
- 内置价格表新增 GPT-6.1 Terra；千问 AI 平台和 QwenCloud 的按量付费改用新的 MaaS 域名。
- 本地路由不再接受带浏览器来源标记的请求，避免网页用掉已保存的供应商额度。
- 修复「打开终端」混入路由和聚合设置、路由模式下 OpenCode Go 等供应商要求重新登录、纯文本模型收到文件后报 400、Windows 供应商表单闪烁、启动时托盘面板打不开、Codex 模型映射用量重复统计、Pi 子代理用量、Pi MCP 导入、models.dev 走代理等问题。
