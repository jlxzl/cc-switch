# CC Switch ZL 4.0.2701

<!-- summary: 同步官方 4.0.26 与 4.0.27：账号订阅计划、一键导入更多应用、会话正文搜索、界面密度与缩放、模型定价搜索等。 -->

本版本基于官方 v4.0.27（第 1 次 ZL 构建），同步官方 4.0.26 和 4.0.27 的全部更新。

## ZL 更新

- 版本号改为 `4.0.2701`：基于官方 v4.0.27 的第 1 次 ZL 构建。

## 上游更新

### 官方 4.0.27

- 会话管理新增「搜索消息正文」，可以按聊天内容找到会话。
- 「设置 → 通用 → 外观」新增界面密度和界面缩放。
- 模型定价表支持按模型 ID 或名称搜索。
- Grok Build 正在使用的供应商卡片可以打开终端。
- Skills 已安装页重新排版；供应商图标跟随深浅色主题。
- 修复配置文件是软链接时被替换成普通文件或写入失败、取消请求后供应商卡在熔断恢复、Codex 自定义权限下 plan 模式报错、运行过的 Skill 误报可更新、Windows 上误认 Python 的 `pi.exe`、模型价格同步超时等问题。

### 官方 4.0.26

- 授权中心和官方供应商卡片显示每个账号的订阅计划，GitHub Copilot 列出全部额度。
- 一键导入链接支持 Claude Desktop、MiniMax Code、Kimi Code、DeepSeek Harness 和 Oh My Pi。
- Codex 卡片可以保留 GPT 模型的官方 Fast 档；系统代理接走本地路由请求时会提醒。
- DeepSeek Harness 可以设置配置目录，装在 WSL 里也能管理。
- 性能优化：供应商列表、主窗口加载、启动、会话读取和路由转发更快，会话同步占着数据库时界面不再卡住。
- 修复 IPv6 不通时经路由请求长时间卡住、需要登录的 MCP 服务器显示连接失败、Claude Desktop 路由卡片改了模型不生效、Copilot 的 Grok 请求报 422 和回复重复显示、非 Retina 显示器上弹窗模糊等问题。
