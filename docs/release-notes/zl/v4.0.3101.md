# CC Switch ZL 4.0.3101

<!-- summary: 同步官方 4.0.31：新增 Copilot CLI 与 WorkBuddy 两个应用、隐私过滤器，界面新增韩语、俄语和德语；修复 Codex 经路由连第三方报 400、Gemini Native 并行工具与缓存等问题。 -->

本版本基于官方 v4.0.31（第 1 次 ZL 构建），同步官方 4.0.29、4.0.30、4.0.31 的全部更新。

## 上游更新

### 官方 4.0.29

- 新增 GitHub Copilot CLI 应用：官方卡打开终端即用 Copilot 自己的登录，自带 Key 的供应商写入 Copilot 原生 `providers.json`，可在 `/model` 里直接选。
- 界面新增韩语和俄语，七种语言改为同步维护，不再回退英文；语言包缺键、空串或变量不一致会让测试失败。
- 修复 Codex 桌面版在 WSL 中运行时用第三方供应商无法启动、经路由连严格 Responses 上游因无 `call_id` 的工具输出报 400、Anthropic 上游被 8192 的 `max_tokens` 默认值截断（默认改为 32000）。
- 修复官方 Codex 路由卡丢失账号模型列表、DeepSeek 经 Mistral 的工具续接 422、只能走本地路由的 Claude Code 卡「打开终端」、Claude 官方卡显示别的账号额度、Antigravity 额度与 Ultra 套餐名称。
- Copilot 空模型列表现在说明原因（多为免费账号无 `model_picker_enabled`），并提示可手填的模型名。

### 官方 4.0.30

- 新增隐私过滤器（设置 → 数据，默认关闭）：路由和聚合模式下，转发前把邮箱、手机号、身份证号、银行卡号、IPv4 和密钥替换成占位符，可选连同工具结果一起过滤；替换不可逆。
- 新增 Claude Fable 5.2 与 Gemini 4 Carbon 的定价。
- 修复第三方原生 Responses 上游拒收 OpenAI 专属字段（`output.encrypted_content`、`stream_options.reasoning_summary_delivery` 等）导致整条请求 400，以及重放工具参数里重复 JSON 键在严格上游持续 400。
- 修复 Windows 主窗口被任务栏挡住、对话框按钮点不到；Antigravity 免费与受限地区账号的额度、agy 1.5 登录、用量同步每分钟重读全部记录占满 CPU；Gemini 流式用量的模型归属与 Vertex 字符串 token 计数。
- 修复 Copilot BYOK 卡被 128K 输入上限限制、编辑器首次打开慢、macOS/Linux 的更新弹窗折叠、OMO Slim 表单点不动等问题。

### 官方 4.0.31

- 新增 WorkBuddy 应用：自定义模型写入它自己的 `models.json`，支持 MCP、Skills、全局提示词、会话与用量，官方登录快照可在授权中心和卡片上切换，显示套餐、积分与到期时间。
- 界面新增德语（第八种语言），README 提供全部八种语言。
- 隐私过滤前移到转发出口：故障转移重试、聚合模式的压缩摘要、Gemini countTokens 包装等都会经过过滤；工具定义保持原样。
- 修复 Claude Code 经 Responses 中转、请求被负载均衡到多个 Azure OpenAI 资源时卡在 400；Gemini Native 把并行工具结果分散到多条消息报 400、每轮 `<total_tokens>` 系统消息破坏前缀缓存。
- 修复 `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` 在路由模式被丢弃、Codex 续接线程用量永不导入、「保持官方登录」开关不立即对当前供应商生效、macOS 托盘提示不消失、快速面板被全屏应用挡住、KDE Wayland 复制按钮失效等问题。
