# CC Switch ZL 4.0.3301

<!-- summary: 同步官方 4.0.32、4.0.33：后台自动下载更新、IP 检测、Ollama Cloud 额度、Windows 切换 Antigravity 账号，并修复切回 Claude 官方后的会话、Gemini Native 模型列表等问题。 -->

本版本基于官方 v4.0.33（第 1 次 ZL 构建），同步官方 4.0.32、4.0.33 的全部更新。

## 上游更新

### 官方 4.0.32

- 新增「自动下载更新」：设置 → 关于打开后，新版本在后台下载并校验，右下角询问是否安装；便携版与 Linux deb / rpm 只能手动安装。
- 设置 → 网络新增 IP 检测：查看经全局代理、临时代理或当前网络的出口 IP、地区与网络信息，仅点击后请求。
- 修复 Codex 经路由续接旧会话时上游先回 200 再报「无法解密」、经路由或聚合接 Mistral 报 422。
- 修复 CC Switch 内部操作崩溃一次后托盘变空、切换不可用，直到重启；用 mise 安装的工具显示两条记录等问题。

### 官方 4.0.33

- 套餐额度查询新增 Ollama Cloud：现行与旧版套餐显示剩余比例和重置时间；本机 Ollama 不会被识别。
- 授权中心的 Antigravity 账号切换支持 Windows（凭据管理器），Linux 仍不支持。
- 修复从第三方切回 Claude 官方后，已开着的 Claude Code 会话仍请求上一家；切换时先把要删的地址、凭据和模型映射写成空值，约 10 秒后再删除。
- 修复 Gemini Native 格式获取模型列表总报「API Key 无效或无权限」；获取模型列表默认带 User-Agent，避免 Cloudflare 拒绝。
- 修复 Antigravity Orchestrator 部分请求未定价、WebDAV 同步在部分 NAS 上失败、WebDAV / S3 上传失败只报「请求构造失败」、S3 自动同步关闭后仍可能上传一次。
- 修复 xAI 额度查询遇网络抖动就要求重新登录、非默认 xAI 账号过期后默认账号被换掉、更新 Skill 中途失败会删掉原版本、Codex 转 Chat 格式时 `required: null` 被严格上游拒绝等问题。
