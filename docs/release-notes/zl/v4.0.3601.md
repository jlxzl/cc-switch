# CC Switch ZL 4.0.3601

<!-- summary: 同步官方 4.0.34–4.0.36：插件页面、技能仓库私有仓库令牌、供应商费用倍率、会话章节；Claude Desktop 模型映射支持直通、分档停用与最大强度。 -->

本版本基于官方 v4.0.36（第 1 次 ZL 构建），同步官方 4.0.34、4.0.35、4.0.36 的全部更新，并含 ZL 自己的更新。

## 上游更新

### 官方 4.0.34

- 技能仓库支持 GitLab、Gitea 和 Forgejo（含自建实例与 Codeberg）的公开仓库。
- 会话管理里可以直接删除 Antigravity CLI 的会话；开启自动下载更新后，发现新版本会立刻开始下载。
- WorkBuddy 手动添加的模型可以设置思考强度；S3 同步可以像 WebDAV 一样清除本机保存的配置。
- 修复 Gemini CLI 获取模型列表报 Key 无效或为空、Codex 里的 Copilot 模型不支持图片、阿里云 OSS / 腾讯云 COS / 华为云 OBS 用不了 S3 同步、Skills 目录有失效链接时云同步上传失败、Copilot 上勾了 1M 的 Fable 请求失败等问题。

### 官方 4.0.35

- 会话管理里显示 Codex `/goal` 的完整目标；请求详情里的请求 ID 可以一键复制。
- 新增 GPT-6.2 Sol / Astra 的价格。
- 修复 Claude Code 的 auto 模式在关不掉思考的模型上被整体拦下、Codex 聚合模式和「打开终端」报 Responses-Lite 需要 `reasoning.context`、Codex 压缩上下文后第一条请求被拒、用量页自定义日期选到很早年份时卡死、Skill 的托管副本不在了就卸载不掉等问题。

### 官方 4.0.36

- 新增插件页面：安装、启用、更新、卸载 Claude Code、Codex、Grok Build、MiniMax Code、OpenClaw、Pi 的插件，并管理插件市场。
- 技能仓库可以用访问令牌读取私有仓库；经本地路由的供应商可以设置费用倍率；会话管理里显示 Claude Code 桌面版的章节。
- 用量统计里价格相同的推理档位合并成一行。
- 修复 Codex 官方额度保护把免费的自动审批也拦下、聚合模式下新发布的官方模型出现很慢、OpenCode 2.x 后 1.x 会话用量不统计、用量页手动输入年份变成 1905、Antigravity 多个模型显示未定价等问题。

## ZL 更新

### Claude Desktop 模型映射：直通、分档停用与最大强度

- 模型映射可以选「直通」：请求里的模型原样发给上游，不做名称替换。
- 每个角色可以单独停用；停用的路由不会出现在 Claude Desktop 的模型菜单里。
- 可以为模型声明最大思考强度，本地代理按声明收敛 Claude Desktop 传来的思考档位。

### Antigravity 模型目录

- 模型下拉不再把中转层的 tiered 别名当成独立家族，不再出现两个「Gemini 4 Hydrogen」。

## 验证边界

- 已过格式检查、类型检查、本次相关的单测与 Rust 编译检查；未跑前端与 Rust 全量单测（存在既有的环境相关偶发失败），未在真实应用中做完整界面走查。
