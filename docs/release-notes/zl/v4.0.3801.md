本版本基于官方 v4.0.38（第 1 次 ZL 构建），同步官方 4.0.37、4.0.38 的全部更新。

## 上游更新

### 官方 4.0.37

- 读不出来的供应商和 MCP 条目单独列出，可以删除，不再被当成空配置覆盖；Pi 新增 Mistral AI 预设；韩语界面翻译整体改进。
- Claude Code 的 1M 标记改写成小写 `[1m]`，已有的 `[1M]` 照常可用；授权中心的账号行更好读。
- 修复本地路由监听地址填 IPv6 时启动不了、「应用到 Claude Code 插件」会清空损坏的 `~/.claude/config.json`、大的技能仓库下载中途被中断、Codex 模型目录探测找不到 Node、工具参数里 `_` 开头的字段被删掉、移出又加回故障转移队列的供应商仍被跳过、插件页点「重试」看起来没反应等问题。

### 官方 4.0.38

- WorkBuddy 支持一键导入链接；Linux 上也能在授权中心切换 Antigravity 账号；Antigravity 的会话列表不再混进空会话和内部子会话，会话阅读器能看到思考、工具调用和结果。
- 会话搜索和用量统计更快，授权中心里 Google 账号的套餐名去掉多余的「Google」。
- 修复 DeepSeek Harness 的配置经 YAML 工具保存后第三方供应商全部消失、Codex 手动选的思考等级有时没生效、名字相近的工具撞名、切到官方模型后报 `invalid_id_prefix`、经路由连 AWS Bedrock 报 400、用量重复计算、缓存写入显示 N/A、Antigravity 输出速度偏低、会话正文搜索失败时误报没有结果、Linux AppImage 里点链接没反应、macOS 全屏窗口被菜单栏遮住、主界面只剩一条白条等问题。
